# MonSiteWeb

Site vitrine réalisé en binôme dans le cadre du TP collaboratif Git & GitHub.

## Sections du site
- **Accueil** : présentation générale et accroche principale.
- **Présentation** : présentation de l'équipe et du projet.
- **Services** : liste des prestations proposées.
- **Témoignages** : avis et retours clients.
- **Contact** : coordonnées et moyens de prise de contact.

## Workflow Git & Retour d'expérience
Travail collaboratif basé sur le **GitHub Flow** : protection de la branche `main`, développement sur des branches dédiées (`ajout-temoignages`, `feature/services-contact`, `branche-accueil-a/b`, `docs/readme`), relecture croisée obligatoire via Pull Requests et résolution d'un conflit de fusion en équipe.
